# Luma changelog

## 0.2.0 — Standard library foundation

### Библиотека и runtime

- Добавлены обычные Luma-модули `math`, `string`, `random`, `io`: 19 публичных
  функций и 3 внутренних helper-функции. `pow`, `sqrt`, `substr` — Luma-обёртки
  над низкоуровневыми primitives, остальные алгоритмы реализованы на Luma.
- RNG Park–Miller/Schrage и random_range с rejection sampling написаны на Luma;
  seed управляемый, поведение детерминированное.
- Добавлены 5 native builtins: `assert`, `type`, `_luma_sqrt`, `_luma_pow`,
  `_luma_slice`. Регистрация и статическая арность берутся из общей таблицы.
- Добавлены stdlib_demo, unit/negative/artifact tests, CLI-сценарии нескольких
  потребителей модулей и запуска `.lbc` после удаления копий stdlib.
- Синтаксис, типы, ImportResolver, Compiler, VM и формат `.lbc` сохранены.
- Новые глобальные builtin-имена заняты runtime; прежние программы с такими
  объявлениями должны переименовать их (см. stdlib/README.md).

### Проверки и публичная документация

- Suite вырос с 226 unit / 43 CLI в 0.1.3 до 244 unit / 57 CLI в 0.2.0.
  Проверены run, vm, неявный запуск, compile, execute, bytecode,
  negative/import cases, RPG и stdlib_demo.
- README и DESIGN переработаны под текущее состояние. Добавлены Language,
  Stdlib, Builtins, CLI, Bytecode, индекс docs, CONTRIBUTING и каталог examples.
- Добавлена проверка Markdown-примеров, всех examples и ссылок.
  Это дополнение к unit/CLI suite, не новая возможность языка.
- ast_demo получил объявление x для обычного запуска; hello обновил устаревший
  комментарий. Намеренный analyzer_demo и expression-only eval_demo обозначены.
- Добавлены MIT LICENSE и .gitignore для generated binaries/bytecode.

### Совместимость и ограничения

- Синтаксис, типы, модель import и LBC версии 1 не менялись.
  Артефакт с новыми primitives требует соответствующий runtime.
- Строки/срезы — байты, не Unicode-символы; trim обрабатывает ASCII whitespace.
- RNG детерминированный, не криптографический; автоматического OS seed нет.
- Нет namespaces, файлового IO, GC или sandbox. Циклы ссылок удерживают память.
- Дробные индексы массивов усекаются. Нюансы Analyzer/runtime и порядок
  индексного присваивания между бэкендами описаны в DESIGN.
- При подготовке документации compiler/VM/runtime/stdlib не изменялись.

## 0.1.3 — Stability & polish

- Исправлено чтение за концом строки с завершающим escape.
- Добавлены байтовые колонки lexer/parser и неизвестных идентификаторов;
  CLI печатает путь, исходную строку и доступный указатель ошибки.
- Сохранены пути импортированных файлов в синтаксических и семантических
  ошибках; корневой файл участвует в цепочке циклического импорта.
- Ограничены глубина import и ресурсы VM. Ограничения документированы в README.
- Усилена проверка неиспользуемых прототипов и размеров секций `.lbc`;
  неизвестная версия формата имеет отдельное сообщение.
- Пустой ввод `num()` сообщает ошибку вместо числа 0.
- Исправлены NaN-индексы, вывод больших/non-finite чисел и циклических массивов.
- Исправлены генерация неявного RETURN, переполнение пула констант и
  16-битных счётчиков аргументов/элементов массивов.
- Сравнения `<=` и `>=` с NaN теперь совпадают в VM и интерпретаторе.
- CLI проверяет неизвестные команды, лишние аргументы флагов, ловит
  стандартные исключения и дизассемблирует `.lbc` через `bytecode`.
- Добавлены регрессионные unit-тесты и самостоятельный Windows CLI test suite.
- Формат байткода, синтаксис и набор типов сохранены.
