# Встроенные функции Luma 0.2.0

[Индекс](README.md) · [Стандартная библиотека](STDLIB.md).
Все 11 builtins доступны без import в начальном глобальном окружении.
Первые 8 — обычный пользовательский API. Три `_luma_*` — низкоуровневые
primitives для stdlib: **технически их может вызвать любой код**,
отдельного контроля доступа нет. Предпочитайте библиотечные обёртки.

Аргументы не преобразуются автоматически. Кроме print, количество аргументов
фиксировано. Analyzer проверяет арность известного имени; динамические вызовы
проверяются runtime. Типы и значения проверяются при исполнении.
Повторное глобальное объявление builtin-имени — ошибка; вложенное теневание
возможно. Не переназначайте builtins, если используете stdlib, полагающуюся на них.

## print

`print(value, ...)`: ноль или больше значений любого типа.
Печатает через один пробел, завершает переводом строки, возвращает nil.
Без аргументов печатает пустую строку. Строки без кавычек, функции как
`<function>`, массивы как `[1, 2]`; циклы обозначаются `[<cycle>]`.
Слишком глубокая вложенность при форматировании — LumaError.
Общий формат числа не является lossless сериализацией double.

```luma
print("sum", 2 + 3, true, nil)
print()
```

## len

`len(value)`: ровно одна строка либо массив. Возвращает number —
число байтов строки или элементов массива, включая 0.
Другой тип: `cannot take length of ...`.

```luma
print(len("Лума"), len([1,2]), len([])) # 8 2 0
```

## push

`push(array, value)`: массив и произвольное значение.
Добавляет элемент в конец, возвращает тот же массив; все aliases видят изменение.
Не массив: `cannot push to ...`. Общий размер массива ограничен доступной памятью.

```luma
let a = []
assert(push(a,7) == a, "push returns its argument")
print(a) # [7]
```

## str

`str(value)`: любое значение → string с тем же представлением, что print.
Для строки возвращает её содержимое, без дополнительных кавычек.
Слишком глубокий массив — ошибка форматирования. Это не JSON и не round-trip
сериализация произвольных значений.

```luma
print(str(nil), str([1,2]), str(print)) # nil [1, 2] <function>
```

## num

`num(text)`: только string → number. Основан на C++ `strtod`;
после распознанного числа не должно остаться ни одного байта.
Поддерживает знак и экспоненциальный **текст**; это не расширяет синтаксис литералов.
В текущей сборке ведущие ASCII-пробелы допустимы, завершающие — нет.
Разбор зависит от C runtime/locale; не используйте локализованную запись числа.
Неконечные результаты, включая `num("nan")`, `num("inf")` и переполнение,
**не отклоняются**. Для конечных чисел применяйте собственную проверку либо stdlib math.
Пустая строка и неправильный текст дают `cannot convert '...' to a number`;
иной тип — `num() expects a string, got ...`.

```luma
print(num("-12.5"), num("1e3"), num(" 2")) # -12.5 1000 2
```

```luma
print(num("12 "))
```

## input

`input()`: без аргументов, читает строку stdin целиком, включая пробелы,
без завершающего LF; возвращает string. Пустая строка → `""`,
EOF или неудавшееся чтение → nil. Число `"15"` остаётся строкой.
На обычном Windows text-mode вводе CRLF обрабатывается стандартным потоком;
Luma не делает дополнительный trim. Аргументы дают ошибку арности.

<!-- luma-check: input Ada -->
```luma
let name = input() or "Guest"
print(name)
```

Перед `num(input())` проверьте EOF. Пустая строка truthy, поэтому `or`
не заменяет её значением по умолчанию.

## type

`type(value)`: любое значение → одна из строк:
`"nil"`, `"boolean"`, `"number"`, `"string"`, `"array"`, `"function"`.
Native-функции и Luma-замыкания возвращают одинаковое `"function"`.
Никаких новых типов или преобразований не создаёт; ошибка только неверной арности.

```luma
print(type(123), type("hello"), type([]))
print(type(nil), type(false), type(print))
```

Результат: `number string array`, затем `nil boolean function`.

## assert

`assert(condition, message)`: любое условие и обязательная строка.
Обычная truthiness: false/nil ложны, 0 и пустая строка истинны.
Успех → nil; ложное условие → LumaError с message.
Message другого типа — ошибка даже при истинном условии.
Аргументы вычисляются до проверки; assert не является ленивой конструкцией.

```luma
assert(0, "zero is truthy")
print(assert(true, "ok")) # nil
```

<!-- luma-check: error -->
```luma
assert(false, "expected failure")
```

## Низкоуровневые native primitives

### _luma_sqrt

`_luma_sqrt(value)`: конечный number >= 0 → number, C++ std::sqrt.
Неверный тип, NaN/inf или отрицательное значение — ошибка.
Публичная обёртка — `sqrt` из math.

```luma
print(_luma_sqrt(9)) # 3
```

### _luma_pow

`_luma_pow(base, exponent)`: два конечных number → конечный вещественный number,
C++ std::pow. Неверный тип/NaN/inf — ошибка; результат NaN/inf из-за
домена или переполнения — `pow result is outside the finite real-number domain`.
`0^0` возвращает 1, отрицательная степень нуля — ошибка;
underflow до 0 допустим. Публичная обёртка — `pow` из math.

```luma
print(_luma_pow(2,-3)) # 0.125
```

### _luma_slice

`_luma_slice(text, start, count)`: string и два конечных неотрицательных
целых number → string. Возвращает count байтов с позиции start (нумерация с 0).
Весь диапазон обязан помещаться в строке; start == len(text) допустим только
при count == 0. Тип, дробная/отрицательная граница или выход за строку —
LumaError. Не округляет границы, в отличие от индексации массива.
UTF-8 может быть разрезан. Публичная обёртка — `substr` из string.

```luma
print(_luma_slice("Luma",1,2)) # um
```
